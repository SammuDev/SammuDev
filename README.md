# 👦 Samuel Santos 🎲

**`Engenheiro de Dados`**

Meu nome é Samuel e sou um Engenheiro de Dados focado em transformar dados brutos em ativos de valor. Minha paixão reside na arquitetura, construção e otimização de pipelines de dados robustos e escaláveis

Utilizo o Python para processamento e automação, orquestro fluxos complexos com Apache Airflow, e construo transformações e modelos de dados de alta qualidade usando dbt. Possuo ampla experiência em processamento distribuído com Apache Spark e ambientes Databricks, além de forte domínio em SQL para manipulação e gerenciamento de dados em bancos como o PostgreSQL

Estou sempre buscando as soluções mais eficientes para os desafios de Big Data e DataOps

## Sobre mim

- 🤔 Explorando novas tecnologias e desenvolvendo soluções de Engenharia de Dados e Big Data
- 🎓 Estudando Ciência da Computação
- 💼 Engenheiro de Dados com stacks em Python, SQL, Databricks, Spark, Dbt e Airflow
- 🌱 Aprendendo mais sobre melhorias em Arquiteturas e pipelines de dados
